# עין משפט הפוך

מפתח הפוך לעין משפט של הש"ס. לכל הלכה ברמב"ם ובשולחן ערוך (ובהמשך גם בטור) הוא מציג את המקומות בגמרא שהעין משפט מפנה מהם אליה.

## מטרה

העין משפט מפנה **מהגמרא** אל הפוסקים. הפרויקט הופך את הכיוון:

```
רמב"ם, הלכות X פרק Y הלכה Z   →  [ברכות ב.,  שבת קיא:, ...]
שו"ע או"ח סימן N סעיף M        →  [ברכות ב., ...]
טור (שלב ב')                    →  [...]
```

## שלבים

1. **איסוף נתונים**: חילוץ הפניות העין משפט מכל דפי הש"ס (מסכת, דף, עמוד, אות, יעד).
2. **נרמול**: פיענוח ההפניה לפורמט אחיד:
   - רמב"ם: ספר, הלכות, פרק, הלכה
   - שו"ע: חלק, סימן, סעיף
   - טור: חלק, סימן
3. **היפוך**: בניית אינדקס מהיעד אל המקורות בגמרא.
4. **פלט**: קבצי JSON ו-CSV, ובהמשך גם תצוגה נוחה (אתר או מסמך).

## מבנה התיקייה

```
data/raw/        נתוני מקור כפי שהורדו
data/processed/  הפניות מנורמלות
scripts/         סקריפטים לאיסוף, פיענוח והיפוך
output/          האינדקס ההפוך המוכן
```

## מקורות נתונים אפשריים

| מקור | הערות |
|------|-------|
| Sefaria: ייצוא הקישורים (GitHub Sefaria-Export, Hugging Face `Sefaria/links`) | קישורי גמרא↔רמב"ם↔שו"ע במבנה מסודר. צריך לבדוק אם אפשר לסנן רק את קישורי העין משפט |
| ויקיטקסט: "עין משפט ונר מצוה" | העתקה לפי דפים. רוב הדפים מסומנים כ"לא בדוק" |

## סטטוס

שלד ראשוני. ההוראות להמשך יגיעו בהמשך.

## ממצאים (נובמבר 2026)

- בקבצי הקישורים של ספריא, הקישורים מסוג `ein mishpat / ner mitsvah` ו-`ein mishpat` מסומנים בנפרד, ולכן אפשר לסנן אותם.
- **הכיסוי חלקי.** יש נתונים ל-20 מסכתות בבלי בלבד: ברכות, עירובין, ביצה, מגילה, חגיגה, כתובות, גיטין, קידושין, בבא קמא, בבא מציעא, בבא בתרא, מכות, הוריות, עבודה זרה, מנחות, חולין, בכורות, ערכין, כריתות ומעילה. יש גם חלק מהירושלמי.
- חסרות בין היתר המסכתות: שבת, פסחים, יומא, סוכה, ראש השנה, תענית, מועד קטן, יבמות, נדרים, נזיר, סוטה, סנהדרין, שבועות, זבחים, תמורה ונדה. עבורן יש להשתמש במקור נוסף.

## הרצה

```bash
mkdir -p data/raw/sefaria_links
for i in $(seq 0 12); do curl -o data/raw/sefaria_links/links$i.csv https://storage.googleapis.com/sefaria-export/links/links$i.csv; done
python3 scripts/build_reverse_index.py
```

הפלט נשמר בתיקייה `output/`, בקבצים `rambam.*`, `shulchan_arukh.*` ו-`tur.*`.
